# DigiDoc Documentation Package

Start with `DIGIDOC_MASTER_MCP.md` for the single all-in-one project guide.
`docs/PROJECT_DOCUMENTATION.md` contains the expanded architecture, stack, roles, features, project tree, data model, API proposal, security, test plan, and roadmap.

## Files
- `DIGIDOC_MASTER_MCP.md` — compact all-in-one MCP + project master document.
- `docs/PROJECT_DOCUMENTATION.md` — complete product and technical specification.
- `mcp-server/index.ts` — starter MCP server scaffold.
- `.mcp.json` — sample local MCP client configuration.
- `.env.example` — placeholder environment variables only.
- `supabase/migrations/README.md` — database migration notes.

## Important
This is documentation and starter code, not a production healthcare system. The API routes are proposed and need implementation. Clinical triage requires licensed review. Use synthetic data in demos and do not claim real appointments without confirmation from a real scheduling provider.
